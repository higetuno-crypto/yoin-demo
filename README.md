# 余韻 YOIN — スクロール連動 3D サイト（試作）

架空のオーディオブランド「余韻」の試聴室を、**スクロールで進む一続きの3D空間**として構築したデモです。

**実在の企業・製品とは関係ありません。** ブランド名・仕様・数値はすべて架空のものです。

---

## 何を証明するためのものか

**3Dモデルを1つも読み込まずに、コードだけで空間・光・質感を作れること。**

- `.glb` / `.gltf` の読み込みは**ゼロ**。寺でも家具でもモデルは使っていません
- 形はすべて `BoxGeometry` `CylinderGeometry` `ConeGeometry` `SphereGeometry` `TorusGeometry`
- 木目・ブラシ仕上げ・音響パネル・カーペット・スピーカーのコーン紙は
  すべて `<canvas>` で**その場で描いたテクスチャ**（画像ファイルなし）
- 金属を映すための環境マップも、コードで生成した 256×128 のグラデーション

外部から読むのは `vendor/three.module.min.js` と `three.core.min.js` の2本だけです。

## 実装のポイント

### スクロールを「正確な状態」と「滑らかな状態」に分ける

```js
rig.exact  = progressFromScroll(scrollY);   // UI・章判定・再現性はこちら
rig.smooth = damp(rig.smooth, rig.exact, 4.4, dt);   // カメラの補間だけこちら
```

章表示やナビゲーションが減衰後の値を読むと、章のラベルが遅れて切り替わります。
**同じスクロール位置は、順方向でも逆方向でも同じ状態を再現します**（テストで検証済み）。

### ポスト処理は自前

`EffectComposer` も `UnrealBloomPass` も使っていません。素の `WebGLRenderTarget` に
リニアで描き、輝度抽出 → 分離ガウシアンぼかし → 合成の順で処理し、
**合成パスが露出・ACESトーンマッピング・ビネット・フィルムグレイン・sRGB変換をまとめて持ちます。**
加工前のフレームを先に完成させてから仕上げる、という順序を守るためです。

### 物理単位のライティング

three.js r165 以降、ライトは物理単位のみです。点光源・スポットは距離の二乗で減衰するため、
旧来の感覚の数値ではまったく足りません（この実装では `DirectionalLight` 2.3、
スポット 11〜34）。一方、**真空管のような至近距離の実光源に `decay: 2` をそのまま使うと
0.1m先で約100倍の照度になり白飛びする**ので、そこだけ `decay: 1.5` にしています。

### アクセシビリティ

- 見出しは単語ごとに出しますが、`aria-label` に完全な文を残しています
- `prefers-reduced-motion` では**連続描画を行わず**、構成済みの静止フレームを1枚出します
- **WebGLが使えない環境ではポスターと本文が残ります**（検証済み）
- キャンバスは `aria-hidden`。意味はすべてDOM側にあります

```bash
python -m http.server 8731 --bind 127.0.0.1
# → http://127.0.0.1:8731/_selftest.html
```

内容: 実際に描画されたか（**ピクセルを読み戻して確認**）／描画コストが予算内か／
カメラ・霧・章番号が章ごとに変わるか／**逆スクロールで同じ状態に戻るか**／
中間位置が両端の間にあるか／**最終章で室内照明が落ち真空管だけが残るか**／

## 既知の制限

正直に書いておきます。

- **章がまだ3つです。** 予定している「扉（通過）」「振動板（接写）」「着席（正対）」が
  未実装で、そのぶん空間の関係の種類が足りません
- **前景レイヤーが無い。** ビューポート手前に置く近景（扉枠など）は奥行きの
  主因のひとつですが、まだ入れていません
- 暖色と寒色の対比は入れましたが、**まだ暖色に寄っています**
- 左のスピーカーは文字の裏に入るため、暗いままで見せ場がありません
- 中間スケールのディテールは追加しました（スピーカーケーブル・電源線・ラグ・
  壁の胴縁・レコード）が、端子やネジ頭など**近接に耐える密度はまだ不足**です
- レコードは `InstancedMesh` にしましたが、ドライバーのボルトなど他の
  繰り返し部品は個別メッシュのままです
